FINANCE API

ExchangeRate API

Retrieve current exchange rates for currencies.

Request

GET https://open.er-api.com/v6/latest/USD

Authentication

None for open endpoint

Parameters

NameTypeDescription
basestringBase currency code, for example USD

Example request

GET https://open.er-api.com/v6/latest/USD

Example response

{
  "result": "success",
  "base_code": "USD",
  "rates": {
    "INR": 87.1
  }
}
